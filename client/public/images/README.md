# Public Image Assets (`client/public/images/`)

> High-resolution banner artwork, campus hero graphics, and optical glare textures.

---

## 1. Inventory & Asset Specifications

| Asset File | Dimensions & Format | Usage Context |
| :--- | :--- | :--- |
| `campus-hero.jpg` | 1920x800 JPEG | Main banner on Home Dashboard showcasing 3D campus coordination equipment (badminton, coffee, books, controller). |
| `flare-highlight.png` | Transparent PNG | Optical specular glare overlay used across premium glassmorphic cards and modal headers. |

---

## 2. Asset Standards
- **Aspect Ratio**: 16:9 or 21:9 for dashboard banners.
- **Maximum File Size**: Keep static raster assets under 600KB to maintain sub-second mobile page loads.
